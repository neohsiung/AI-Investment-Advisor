# Distill Insight

萃取 alert/報告的核心洞察並寫入 cognitive_memories 記憶系統。

## When to Use

- 當各類分析報告或警報產生後，需要將核心見解沉澱入長期認知記憶時。
- 提取市場重大事件的關鍵學習成果以供後續反思。
