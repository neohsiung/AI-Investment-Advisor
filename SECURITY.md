## Reporting a Vulnerability

We take the security of this project seriously. If you find any security vulnerability, please do NOT open a public issue.

Instead, please report it by emailing [your-email@example.com](mailto:your-email@example.com). You should receive a response within 48 hours.

Include as much info as possible to help us reproduce the issue.
