---
description: 本流程於專案執行（Execution）結束後自動觸發。它會掃描當前程式碼變更、提取註解或自動生成更新說明，並將其迭代至 GitHub Project Wiki 儲存庫中。這確保了開發文件與程式碼版本實時同步，消除手動更新文件的延遲。
---

1. 開始開發之前依照 @文件框架定義-Document-Frameworks 和 @文件規範-Wiki-Standard 先迭代非取代目前的的文件，若有更好的資料夾結構可視情況調整
2. 文件內容確認後才開始開發
3. 開發完成後，移除或Archive不必要的程式碼和玩見
4. 最後需確保整體專案測試覆蓋率 > 75%
