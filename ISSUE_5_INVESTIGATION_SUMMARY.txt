## Root Causes (4 Critical Issues)

### 🔴 CRITICAL #1: Async/Sync Mismatch in job_etoro_sync()
**Location**: `src/services/scheduler_service.py:183-203`

The Broker Sync job calls an async method WITHOUT await in a synchronous context:
```python
def job_etoro_sync(self):  # SYNC FUNCTION
    broker = BrokerFactory.get_broker(self.user_id)
    result = broker.sync_history(self.user_id)  # ❌ ASYNC METHOD, returns coroutine
    # Tries to access: result['added']  # 💥 FAILS: coroutine not iterable
```

**Impact**: ALL broker syncing disabled, every 4 hours fails
**Error Pattern**: Repeating every 4 hours, 100% failure rate

---

### 🔴 CRITICAL #2: Corrupted celery_app.py
**Location**: `src/infrastructure/celery_app.py` (entire file)

File is truncated/incomplete:
- Line 5 cuts off mid-URL: `redis_url = os.getenv("REDIS_URL", "redis://redis:***@worker_process_init.connect`
- Missing: Celery configuration, beat schedule, logger setup
- Lines 6-37 in original are corrupted

**Impact**: Sentinel health checks fail every 2 minutes trying to import celery_app
**Log Spam**: 50+ errors/hour

---

### 🟡 MEDIUM #3: Missing Redis Connection
**Location**: Scheduler container environment

Redis is not accessible from scheduler container (port 6379 refused)
- Cache initialization fails
- Doesn't block task execution but limits functionality

---

### 🟡 MEDIUM #4: Database Schema Mismatch
**Location**: `src/services/billing_service.py`

Column `users.current_billing_cycle_start` doesn't exist in database
- Migration not applied
- Causes errors when billing service queries user
